# MindFlow - Приложение для управления сессиями фокуса

MindFlow - это мобильное приложение для управления продуктивностью с использованием техники Pomodoro. Приложение помогает пользователям сосредоточиться на задачах, отслеживать прогресс и достигать целей через систему достижений и наград.

## Особенности

- ⏱️ **Таймер сессий** - Настраиваемые сессии фокуса с автоматическими перерывами
- 🔕 **Блокировка уведомлений** - Автоматическое отключение уведомлений во время работы
- 📊 **Статистика** - Подробная аналитика за день, неделю и месяц
- 🏆 **Достижения** - Система наград, медалей и уровней
- 🤖 **AI-адаптация** - Умные рекомендации на основе ваших паттернов
- 💾 **Оффлайн работа** - Полная функциональность без интернета
- 🔊 **Звуковые уведомления** - Оповещения о начале/конце сессий
- 📈 **Отслеживание целей** - Мониторинг прогресса к дневной цели

## Требования

- **iOS**: 13.0 и выше
- **Android**: 6.0 (API 23) и выше
- **Node.js**: 16.0 и выше
- **Expo CLI**: 6.0 и выше

## Установка

### 1. Клонирование репозитория

```bash
git clone <repository-url>
cd mindflow
```

### 2. Установка зависимостей

```bash
npm install
# или
yarn install
```

### 3. Инициализация Expo

```bash
npx expo prebuild
```

### 4. Запуск в режиме разработки

```bash
npx expo start
```

После этого вы можете:
- Нажать **`i`** для запуска на iOS симуляторе
- Нажать **`a`** для запуска на Android эмуляторе
- Отсканировать QR-код приложением Expo Go для запуска на физическом устройстве

## Экраны приложения

### HomeScreen
Главный экран с большой кнопкой для начала сессии, прогрессом дня и мотивационным сообщением.

### SessionScreen
Экран активной сессии с таймером, кнопками управления и блокировкой уведомлений.

### SessionCompleteScreen
Экран поздравления после завершения сессии с показом статистики и полученных наград.

### BreakScreen
Экран перерыва с таймером отдыха и рекомендациями для восстановления.

### StatisticsScreen
Подробная статистика с графиками за день, неделю и месяц.

### SettingsScreen
Настройки длительности сессий, перерывов, уведомлений и звука.

### AchievementsScreen
Галерея достижений, медалей и уровней прогресса.

## Конфигурация базы данных

Приложение использует SQLite для хранения данных. База данных автоматически создается при первом запуске с следующими таблицами:

- **sessions** - История сессий фокуса
- **breaks** - История перерывов
- **achievements** - Разблокированные достижения
- **settings** - Пользовательские настройки
- **user_stats** - Статистика пользователя

## Основные сервисы

### DatabaseService
Управление SQLite базой данных, CRUD операции для всех таблиц.

### TimerService
Управление таймерами сессий и перерывов с поддержкой фоновой работы.

### NotificationService
Управление уведомлениями и блокировкой уведомлений во время сессий.

### StatisticsService
Расчет и агрегация статистики, аналитика использования.

### AchievementService
Управление достижениями, проверка условий разблокирования.

### AIAdaptationService
Анализ паттернов и предоставление умных рекомендаций.

### SoundService
Воспроизведение звуков и управление вибрацией.

## Кастомные хуки

- **useSession** - Управление состоянием текущей сессии
- **useTimer** - Логика таймера с обратным отсчетом
- **useStatistics** - Получение и обновление статистики
- **useSettings** - Управление настройками приложения
- **useAchievements** - Работа с достижениями
- **useNotifications** - Управление уведомлениями
- **useDatabase** - Инициализация и работа с БД

## Система достижений

Приложение включает следующие категории достижений:

- **Первые шаги** - Завершение первой сессии
- **Трудолюбие** - Завершение 10, 50, 100+ сессий
- **Последовательность** - Серии завершенных дней подряд
- **Мастер фокуса** - Достижение определенного времени фокуса
- **Ранняя пташка** - Сессии в ранние часы
- **Ночной сумасшедший** - Сессии поздно вечером
- **Специалист** - Завершение сессий в определенное время

## Решение проблем

### Приложение не запускается

1. Убедитесь, что Node.js установлен: `node --version`
2. Очистите кэш: `npm cache clean --force`
3. Переустановите зависимости: `rm -rf node_modules && npm install`
4. Очистите Expo кэш: `npx expo prebuild --clean`

### Проблемы с базой данных

1. Удалите базу данных приложения через настройки устройства
2. Переустановите приложение
3. База данных будет пересоздана автоматически

### Уведомления не работают

1. Проверьте разрешения в настройках устройства
2. Убедитесь, что `notifications_blocked` отключен в настройках приложения
3. Перезагрузите приложение
